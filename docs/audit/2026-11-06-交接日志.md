## 5. 约定与坑

- 项目约定在 `AGENTS.md`：每个修复更新 `CHANGELOG.md`（先 `### English` 有序列表，再 `### 中文`），验证后单独本地提交，提交信息用“修复：XXX”“新增：XXX”“优化：XXX”“移除：XXX”，只提交当前任务相关文件。提交末尾加 `Co-Authored-By: Claude ... <noreply@anthropic.com>` 的署名行。
- **CRLF 文件**：仓库大部分是 LF，但这五个文件在 git 里是 CRLF：`dependencies.gradle`、`gradle.properties`、`src/main/java/com/lhy/wcwt/compat/jei/WcwtRecipeTransferHandler.java`、`src/main/java/com/lhy/wcwt/init/ModComponents.java`、`src/main/java/com/lhy/wcwt/menu/WirelessComprehensiveWorkTerminalMenu.java`。用脚本改完后要恢复 CRLF（例如 `perl -pi -e 's/\r?\n/\r\n/'`），否则一次提交会变成整文件 diff。用 `git ls-files --eol <file>` 可查。
- 单元测试凡是碰 `ItemStack` 或 `AEItemKey` 的，`@BeforeAll` 里调用 `TestBootstrap.ensure()`；不要再各自写一套 `Bootstrap.bootStrap()` 加 AE2 键类型注册，同一 JVM 里只能注册一次。
- 菜单类 5100 行、界面类 6500 行，读的时候分段。审计报告里的行号对应各自撰写时的代码，修复后会漂移，按内容定位。
- 可选模组的类只能在 `ModList.isLoaded` 门控后的嵌套类里引用（仓库里的 `Impl` / `Integration` 模式），`instanceof` 也算引用。阶段一的 C-1 就是违反这条导致的崩溃。
- 网络包：服务端处理函数里的异常只会被 NeoForge 记日志，不会踢人；解码阶段的异常才会断开发送方。客户端提供的下标、数量、字符串长度都要在服务端校验，`WcwtPacketLimits` 里有现成的工具。
- `WcwtPacketThrottle` 提供每玩家每 tick 的包预算，已用于拉取与样板管理动作。
